🚀 Integration Steps

Step 1: Copy Files

// Copy to these locations:
src/main/java/controllers/PackInscriptionViewController.java
src/main/java/Services/PackInscriptionService.java
src/main/resources/fxml/PackInscriptionView.fxml
src/main/resources/css/pack-inscription.css
src/main/resources/css/pack-inscription-animations.css

Step 2: Update Navigation (in Menu.fxml or Main.java)

<Button text="S'inscrire au Pack" onAction="#goToPackInscription" 
        styleClass="btn-primary"/>

Step 3: Add Navigation Handler

@FXML
private void goToPackInscription() {
    try {
        SceneUtils.switchScene("PackInscriptionView.fxml");
    } catch (Exception e) {
        e.printStackTrace();
    }
}

Step 4: Update CSS Stylesheet (Optional)

If main stylesheets don't include these, add to your FXML:

<stylesheets>
    <String fx:value="@../css/pack-inscription.css"/>
    <String fx:value="@../css/pack-inscription-animations.css"/>
</stylesheets>

🎬 Usage Examples

Load Pack Inscription Page

FXMLLoader loader = new FXMLLoader(
    getClass().getResource("/fxml/PackInscriptionView.fxml")
);
VBox root = loader.load();
Scene scene = new Scene(root);
primaryStage.setScene(scene);
primaryStage.show();

Create Inscription via Service

PackInscriptionService service = new PackInscriptionService();

Inscription insc = service.createInscription(
    userId,           // int
    packId,            // int
    nbPersonnes,       // int
    promoCode,         // String
    paymentMethod      // "CARD", "MOBILE", "BANK"
);

Process Payment

Map<String, String> paymentDetails = new HashMap<>();
paymentDetails.put("cardNumber", "1234 5678 9012 3456");
paymentDetails.put("expiry", "12/25");
paymentDetails.put("cvv", "123");

PaymentResult result = service.processPayment(
    inscriptionId,
    "CARD",
    paymentDetails
);

🐛 Common Issues & Solutions

CSS Not Loading

Problem: Styles don't appear

Solution:

  • Verify CSS files are in src/main/resources/css/
  • Rebuild project (clean + build)
  • Check stylesheet paths in FXML

Pack Data Not Loading

Problem: Packs grid is empty

Solution:

  • Ensure PackService is implemented
  • Check database connection in MyDB2
  • Verify packs exist in database
  • Check console for error messages

Payment Button Disabled

Problem: Cannot process payment

Solution:

  • Fill all required form fields
  • Select a pack first
  • Check payment service configuration

📞 Support & Troubleshooting

Check Console Logs

Most issues will print to console. Look for:

  • ✅ - Success messages

Verify Setup

  • All files copied to correct locations
  • FXML namespace declarations correct
  • CSS stylesheet paths valid
  • Database connection working
  • Services properly implemented
